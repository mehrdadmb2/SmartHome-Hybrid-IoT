# 🏠 SmartHome-Hybrid-IoT

**یک سیستم نظارت و کنترل هوشمند خانگی ترکیبی (داخلی/آنلاین) مقاوم در برابر خطا**

این پروژه شامل چندین نود (ESP32، ESP32-S3، Arduino Uno) است که به‌صورت مستقل عمل می‌کنند، داده‌ها را جمع‌آوری کرده و از طریق یک هاب مرکزی (ESP32) در حافظهٔ SD ذخیره می‌نمایند. یک وب‌سایت داخلی (Local Dashboard) و یک وب‌سایت آنلاین (GitHub Pages) امکان مشاهدهٔ لحظه‌ای داده‌ها، نمودارها، وضعیت نودها و کنترل از راه دور درب را فراهم می‌کند.

---

## ✨ ویژگی‌های کلیدی

- **معماری توزیع‌شده و مقاوم به خطا** – هر برد در صورت قطع ارتباط، وظیفهٔ اصلی خود را انجام می‌دهد.
- **نمایش زندهٔ دما و رطوبت** روی OLED برای هر نود.
- **ذخیره‌سازی داده‌ها در فرمت CSV** روی SD Card (قابل باز شدن با Excel).
- **وب‌سایت محلی مدرن** (Cyberpunk UI) – اجرا روی هاب ESP32 بدون نیاز به اینترنت.
- **وب‌سایت آنلاین** با تم سایبرپانکی – هاست رایگان روی GitHub Pages.
- **پشتیبانی از تاریخ شمسی و میلادی** + ساعت دقیق.
- **نمودارهای تعاملی** (Chart.js) با فیلترهای ساعتی، روزانه، هفتگی و ماهانه.
- **آمار باز شدن درب** با تفکیک UID تگ‌های RFID.
- **پنل وضعیت نودها** (آنلاین/آفلاین) + آخرین زمان به‌روزرسانی.
- **بارگذاری خودکار فایل‌های CSV روی GitHub** هر ۳۰ دقیقه.
- **به‌روزرسانی خودکار داشبورد داخلی از GitHub** هنگام راه‌اندازی.
- **پاک‌سازی خودکار SD Card** – حذف قدیمی‌ترین فایل‌ها در صورت کمبود فضا.
- **باز کردن درب از طریق داشبورد داخلی** (کنترل امن داخل شبکه).

## 🔌 سیم‌کشی (Pinout)

### 1. Arduino Uno
| Arduino Pin | قطعه          |
|-------------|---------------|
| 10 (SS)     | RFID SDA      |
| 13 (SCK)    | RFID SCK      |
| 11 (MOSI)   | RFID MOSI     |
| 12 (MISO)   | RFID MISO     |
| 9           | RFID RST      |
| 8           | رله (سیگنال)  |
| 2 (RX)      | ← ESP32 TX2 (با مقسم ولتاژ) |
| 3 (TX)      | → ESP32 RX2   |

### 2. ESP32 Hub
| ESP32 Pin | قطعه          |
|-----------|---------------|
| 5 (SDA)   | OLED SDA      |
| 4 (SCL)   | OLED SCL      |
| 13        | DHT22 DATA    |
| 16 (RX2)  | → Arduino TX  |
| 17 (TX2)  | ← Arduino RX (مقسم ولتاژ) |
| 27 (CS)   | SD Card CS    |
| 23 (MOSI) | SD Card MOSI  |
| 19 (MISO) | SD Card MISO  |
| 18 (SCK)  | SD Card SCK   |

### 3. ESP32-S3
| ESP32-S3 Pin | قطعه          |
|--------------|---------------|
| 5 (SDA)      | OLED SDA      |
| 4 (SCL)      | OLED SCL      |
| 6            | DHT22 DATA    |

> **نکته مهم:** خط TX آردوینو (5V) باید توسط یک مقسم ولتاژ به 3.3V تبدیل شود تا به RX2 ESP32 (پایه 16) آسیبی نرسد.

## 🚀 راه‌اندازی گام‌به‌گام

### 1. ساخت مخزن گیت‌هاب و تنظیم Pages
- مخزن را عمومی (Public) کنید.
- پوشه‌های `docs/`، `site/` و `data/` را مطابق ساختار فوق ایجاد کنید.
- GitHub Pages را روی شاخه `main` و پوشه `/docs` فعال کنید.

### 2. دریافت توکن گیت‌هاب
- به `Settings` → `Developer settings` → `Personal access tokens (classic)` بروید.
- یک توکن جدید با دسترسی `repo` (یا `public_repo`) بسازید.
- توکن را در فایل `config.txt` روی SD Card قرار دهید (توضیح بعد).

### 3. آماده‌سازی SD Card
- SD را با فرمت FAT32 فرمت کنید.
- در ریشه یک فایل `config.txt` با محتوای زیر بسازید:
  ```
  token ghp_XXXXXXXXXXXXXXXXXXXXXXXXXXXX
  ```
- پوشه‌های زیر را ایجاد کنید:
  - `/www` (خالی – هاب فایل‌ها را دانلود می‌کند)
  - `/data` (خالی)

### 4. فلش کردن کدها
- کد **Arduino Uno** را باز کرده و آپلود کنید.
- کد **ESP32-S3** را با برد `ESP32S3 Dev Module` آپلود کنید.
- کد **ESP32 Hub** را با برد `ESP32 Dev Module` آپلود کنید.

### 5. تنظیم IPهای ثابت
- در روتر خود، MAC Address بردها را بیابید و IPهای زیر را رزرو کنید:
  - ESP32 Hub → `192.168.1.119`
  - ESP32-S3 → `192.168.1.115`

## 🧪 رفع خطاهای رایج

| مشکل | راه‌حل |
|-------|---------|
| **OLED روشن نمی‌شود** | آدرس I2C را با یک Scanner تست کنید. احتمالاً 0x3C یا 0x3D است. |
| **خطای `mbedtls_md5_starts_ret`** | نسخه‌های قدیمی ESPAsyncWebServer/AsyncTCP را پاک کنید و نسخه master را نصب کنید. |
| **پوش گیت‌هاب انجام نمی‌شود** | توکن را در `config.txt` بررسی کنید (بدون فاصله اضافه). |
| **سایت داخلی قدیمی می‌ماند** | هاب در هر بوت فایل‌ها را از گیت‌هاب می‌گیرد. از اینترنت آن مطمئن شوید یا فایل‌ها را دستی در `/www` کپی کنید. |
| **ESP32 شناسایی نمی‌شود** | درایور CH340/CP210x را نصب کنید. از کابل دیتا استفاده کنید. |
| **آردوینو داده‌ها را ارسال نمی‌کند** | سیم‌کشی UART و مقسم ولتاژ را بررسی کنید. Baud Rate باید 9600 باشد. |

  سنسورها: `time,temperature,humidity`

  `esp32_1_YYYY-MM-DD.csv`
